# PDF Grabber

Saves PDFs from websites that show them but hide the download button
(like the eclass course viewer).

Works in **Google Chrome** and **Microsoft Edge**.

---

## How to install

1. **Unzip** the folder you were sent. Put it somewhere you won't delete it
   (e.g. `Documents`). If you delete or move the folder later, the extension stops working.

2. Open your browser and type this in the address bar, then press Enter:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`

3. Turn on **Developer mode**.
   - Chrome: toggle in the **top-right** corner
   - Edge: toggle in the **left sidebar**

4. Click **Load unpacked** and select the `pdf-grabber` folder
   (the folder that contains `manifest.json`).

5. Click the **puzzle-piece icon** next to the address bar, then click the **pin**
   next to PDF Grabber so it always shows.

Done. You only do this once.

---

## How to use

1. Go to your course page and **open the PDF** in the viewer.
   If the page was already open before you installed, **refresh it (F5)** first.
2. The PDF Grabber icon shows a **red number**: that's how many PDFs it found.
3. Click the icon, then click **Save** (or **Download all**).
4. Your files are in **Downloads → PDF Grabber**.

### It found nothing / the download failed?

Open the PDF in the viewer, click the icon, and press **Grab from viewer**.

---

## Good to know

- It only saves files you can already see while logged in. Nothing is uploaded anywhere.
- Chrome may show a "Developer mode extensions" warning on startup. That's normal
  for extensions installed this way. Just close it.
- Please follow your school's rules on sharing course materials.

## 中文说明

**安装（只需一次）**

1. 解压收到的文件夹，放在不会删除的位置（例如"文档"）。删除或移动文件夹后插件将失效。
2. 在浏览器地址栏输入 `chrome://extensions`（Edge 浏览器输入 `edge://extensions`），按回车。
3. 打开 **开发者模式**（Chrome 在右上角，Edge 在左侧栏）。
4. 点击 **加载已解压的扩展程序**，选择 `pdf-grabber` 文件夹（里面有 `manifest.json`）。
5. 点击地址栏旁的 **拼图图标**，把 PDF Grabber **固定** 到工具栏。

**使用**

1. 在课程页面打开 PDF。如果页面在安装前就已打开，请先按 **F5** 刷新。
2. 插件图标上会显示 **红色数字**，即找到的 PDF 数量。
3. 点击图标 → **Save**（保存）或 **Download all**（全部下载）。
4. 文件保存在 **下载 → PDF Grabber** 文件夹。

**没找到或下载失败？** 在查看器中打开 PDF，点击图标，再点 **Grab from viewer**。
